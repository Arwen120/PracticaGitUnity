Práctica Git y Git LFS - Unit

Esta práctica consiste en crear un proyecto de Unity y utilizar Git, GitHub Y Git LFS para gestionar el
control de versiones del proyecto. El proyecto contiene: Un cubo con un material turquesa, una esfera con un material negro, una escena principal llamada Main y un script llamado ScriptTarea1_1.cs. El proyecto está gestionado mediante Git y almacenado en GitHub. En el repositorio https://github.com/Arwen120/PracticaGitUnity. Se ha configurado Git LFS para gestionar
archivos de gran tamaño. Además el proyecto contiene un vídeo de más de 100 MB dentro de la carpeta Media, gestionado mediante Git LFS. El archivo .gitattributes contiene las configuraciones necesarias para que los archivos de vídeo sean gestionados mediante Git LFS.
